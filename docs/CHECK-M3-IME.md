# M3 한글 IME 셀 편집 수동 QA 체크리스트

## 목적

브라우저 자동화 도구가 없는 환경에서, 한글 IME(입력기)를 사용하는 셀 편집이
그리드(CanvasGrid)와 WebSocket 편집 경로를 통해 올바르게 동작하는지 사람이 직접 확인한다.
조합(composition) 입력, 키보드 커밋/취소, 스크롤, 트랜잭션 롤백 시 윈도우 캐시 무효화를 중점 검증한다.

## 사전 준비

1. 저장소 루트에서 데모 서버를 실행한다.

   ```sh
   ./target/debug/tablepeek serve --port 7699 --no-open --demo-rows 200000
   ```

   백그라운드로 띄우려면 다음과 같이 실행한다.

   ```sh
   nohup ./target/debug/tablepeek serve --port 7699 --no-open --demo-rows 200000 > /tmp/tablepeek-m3.log 2>&1 &
   ```

2. 브라우저에서 접속한다. (토큰은 서버 실행 시 콘솔에 출력되는 값을 사용한다.)

   ```text
   http://127.0.0.1:7699/?token=<TOKEN>
   ```

3. SQL 에디터에 다음 쿼리를 실행한다. `id`가 PK, `name`이 텍스트 컬럼인 데모 테이블이다.

   ```sql
   SELECT id, name FROM demo LIMIT 100;
   ```

4. 편집 UI 확인: 툴바에 `트랜잭션 시작` 버튼이 보이면 편집 가능한 결과이다.
   (PK가 없는 결과에서는 트랜잭션 버튼과 편집 기능이 비활성화된다.)

참고: 데모 데이터는 서버 프로세스 메모리에 존재하므로 서버를 재시작하면 편집 내용이 초기화된다.
체크리스트 11번은 서버를 재시작하지 않고 같은 쿼리를 다시 실행하는 방식으로 확인한다.

## 체크 항목

| 항목 | 절차 | 기대 결과 | 결과 |
| --- | --- | --- | --- |
| 1. 더블클릭 편집 시작 + 기존 값 선택 | `name` 셀(예: 1행)을 더블클릭한다. | 편집창이 열리고 기존 값 전체가 선택되어 있다. 바로 한글을 입력하면 기존 값이 대체된다. | |
| 2. 한글 조합 중 Enter | 편집창에서 `한글`을 입력하다가 조합이 진행 중인 상태에서 Enter를 누른다. | 조합만 확정되고 편집창은 유지된다. 셀 값이 커밋되거나 편집창이 닫히지 않는다. | |
| 3. 확정 후 Enter 커밋 | 2번 상태에서 다시 Enter를 누른다. | 편집창이 닫히고 서버로 편집이 전송되며, 그리드 셀에 새 값이 표시된다. | |
| 4. Esc 취소 | 편집창에 값을 입력한 뒤 Esc를 누른다. | 편집창이 닫히고 원래 값이 그대로 유지된다. | |
| 5. Tab / Shift+Tab 이동 | 편집 중 Tab(또는 Shift+Tab)을 누른다. 마지막 열에서도 같은 키를 눌러 본다. | 현재 값이 커밋되고 다음(이전) 열의 편집창이 열린다. 경계(첫/마지막 열)에서는 커밋만 되고 이동하지 않는다. | |
| 6. 다른 셀 클릭(blur) 커밋 | 편집창에 값을 입력한 뒤 다른 셀을 클릭한다. | 편집값이 커밋되고 편집창이 닫힌다. 클릭한 셀이 선택된다. | |
| 7. 편집 중 스크롤 | 편집창을 연 상태에서 그리드를 스크롤한다. | 편집이 취소되고 편집창이 닫힌다. 원래 값이 유지된다. | |
| 8. 빈 값 커밋 → NULL | 셀의 기존 값을 모두 지우고 Enter를 누른다. | 서버에 NULL로 저장되고 그리드에 `NULL`(회색)로 표시된다. | |
| 9. 숫자 셀 우측 정렬 | `id` 셀을 편집해 숫자 값을 커밋한다. | 숫자 셀은 계속 우측 정렬로 표시된다. | |
| 10. 트랜잭션 롤백 후 캐시 무효화 | `트랜잭션 시작` 클릭 → 아무 `name` 셀이나 한글로 편집 → `롤백` 클릭. | 롤백 후 그리드가 트랜잭션 이전 값으로 다시 그려진다. (윈도우 캐시가 버려지고 서버에서 재조회된다.) | |
| 11. 편집 후 재실행 → 서버 값 유지 | 셀을 편집한 뒤 `실행`을 눌러 같은 쿼리를 다시 실행한다. | 재조회한 결과에 편집한 값이 그대로 표시된다. | |
| 12. PK 없는 결과 편집 차단 | `SELECT count(*) FROM demo;`를 실행하고 결과 셀을 더블클릭한다. | 편집창이 열리지 않고, 툴바에 트랜잭션 버튼도 표시되지 않는다. | |

## 결과 기록 방법

- 결과 칸에 `통과` 또는 `실패`를 적고, 실패 시 재현 절차와 화면 상태를 비고로 남긴다.
- 2번(조합 중 Enter)과 10번(롤백 캐시)은 한글 IME 환경에서 가장 깨지기 쉬운 경로이므로 반드시 실제 IME로 확인한다.
