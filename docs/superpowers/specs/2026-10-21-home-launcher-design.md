# 홈 화면: 떠 있는 시작 창 + 그룹·오른쪽 클릭 메뉴

작성일: 2026-10-21

## 왜 바꾸는가

지금 홈은 연결 카드 몇 개가 위쪽에 몰려 있고 나머지가 비어 "휑하다". 사용자가 고른 방향은 TablePlus의 웰컴 창이다. 헤더 아래 가운데에 창 하나를 띄우고, 그 안에서 연결을 찾고·묶고·열고·백업한다. 빈 바깥 공간은 의도한 배경으로 둔다.

함께 정리할 것:

- **environment 개념을 없앤다.** 사용자는 태그만 원한다.
- **테이블 개수를 보이지 않는다.** 홈 카드의 "테이블 n개"는 뜻이 분명하지 않고 필요 없다.
- **앱 전체 아이콘을 키운다.** 사용자는 앱 아이콘이 전반적으로 작다고 느낀다.

## 목표

1. 홈 = 헤더 + 가운데 떠 있는 시작 창 하나.
2. 연결을 그룹으로 묶는다. 그룹은 오른쪽 클릭으로 만들고, 연결은 끌어 놓기로 넣고 뺀다.
3. 오른쪽 클릭 메뉴로 만들기, 가져오기, 내보내기, 연결별 작업을 한다.
4. 시작 창에서 바로 데이터베이스 백업·복원을 시작한다.
5. 태그만 남긴다. 테이블 개수는 없다. 아이콘은 앱 전체에서 키운다.

## 하지 않을 것

- **연결 정보 저장 위치는 그대로 둔다.** 프로필은 서버의 `~/.tablepeek/store.json`, 색상·태그·그룹은 브라우저 localStorage에 둔다. 서버로 옮기지 않는다.
- **비밀번호는 내보내지 않는다.** 암호화 내보내기도 하지 않는다.
- **연결 목록에 최근 작업이나 상세 패널을 붙이지 않는다.** 시안 B·C는 채택하지 않았다.
- **헤더를 없애지 않는다.**

## 실패로 볼 것

- 홈에서 열린 연결로 돌아가는 길(헤더 탭)이나 설정이 없어지면 실패다.
- 그룹을 지울 때 안의 연결 프로필이 지워지면 실패다.
- 내보낸 파일에 비밀번호가 들어가면 실패다.
- 기존에 지정해 둔 environment 정보가 흔적 없이 사라지면 실패다. 태그로 옮겨야 한다.

## 화면

### 헤더

지금과 같다. 로고(홈 버튼), 열린 연결 탭, 설정 톱니가 있다.

### 시작 창

- 헤더 아래 영역의 가운데에 떠 있다. 둥근 모서리, 테두리, 그림자를 둔다.
- 크기는 최대 약 760×480이다. 화면이 좁으면 거의 꽉 차게 줄어든다(구체적인 기준은 만드는 사람의 판단).
- 창 바깥 배경은 은은한 그라데이션 정도로 둔다. 밝은·어두운 테마 모두 기존 CSS 토큰을 쓴다.

**왼쪽 칸 (약 250px)**

- 흐린 TablePeek 로고(BrandMark + 워드마크, 투명도 약 0.5)와 그 아래 "로컬 DB 클라이언트"를 둔다.
- 작업 세 가지를 세로로 놓는다. 각각 아이콘 + 글자이고, 아이콘은 지금보다 확실히 크게(배경 있는 칸 약 28px 안에 16px 이상) 한다.
  - **새 연결 만들기…** — 새 연결 창을 연다.
  - **데이터베이스 백업…** — 아래 "백업·복원 흐름"을 따른다.
  - **데이터베이스 복원…** — 아래 "백업·복원 흐름"을 따른다.

**오른쪽 칸**

- 맨 위 줄:
  - **+ 버튼**을 누르면 메뉴가 열린다. 항목은 새 연결…, 새 그룹…, SQLite 파일 열기…, 연결 가져오기 › (URL에서… / 파일에서…).
  - **검색창**은 이름·호스트·DB 이름·태그로 실시간으로 걸러 낸다. 그룹 이름이 맞으면 그 그룹 전체를 보여 준다.
- 그 아래는 스크롤되는 연결 목록이다.

### 목록

- **맨 위**에는 저장하지 않고 열어 둔 연결(데모, 연 SQLite 파일)을 그룹 없이 둔다. 이 줄은 끌어 놓기 대상이 아니다.
- **그다음**에는 그룹에 속하지 않은 저장된 연결을 둔다.
- **그다음**에는 그룹을 둔다. 순서는 만든 순서다.
- 그룹 머리줄은 접기 화살표, 색 있는 원형 그룹 아이콘, 그룹 이름, 접혀 있을 때의 연결 수로 이루어진다. 접힘 상태는 기억한다.
- 그룹 안의 연결은 들여쓰기로 보인다.
- 연결 한 줄의 구성:
  - 기존 DB 로고 배지(`DriverIcon`). **새로 만들지 말고 지금 것을 그대로 쓴다.**
  - 이름.
  - 태그 알약. 연결 색상이 있으면 그 색으로 칠한다. 색만 있고 태그가 없으면 이름 옆에 작은 색 점을 둔다.
  - 두 번째 줄의 `호스트 : DB` (고정폭 글꼴).
  - 오른쪽 끝의 상태. 열려 있으면 "● 연결됨", 아니면 마지막 사용 시간("3시간 전")을 보여 준다. **테이블 개수는 없다.**
- 마우스를 올리거나 키보드 포커스가 오면, 오른쪽 상태 자리가 작업 버튼으로 바뀐다. 버튼은 새 창, 연결 끊기(열려 있을 때), 편집, 삭제다.
- 동작:
  - 클릭, Enter, Space로 연다. 이미 열려 있으면 그 작업 화면으로 가고, 아니면 연결한다.
  - 키보드로 ↑↓ 이동, Enter로 연결할 수 있다. 검색창에서 ↓를 누르면 목록으로 들어간다.

### 연결이 하나도 없을 때

**언제 보이나**: 저장된 연결, 열린 연결, 그룹이 모두 없을 때다. 빈 그룹이 하나라도 있으면 일반 목록을 보여 준다.

같은 창을 쓴다. 왼쪽 칸은 그대로 두고, 오른쪽 칸의 맨 위 줄(+ 버튼과 검색창)도 그대로 둔다. 목록 자리에는 지금의 첫 실행 안내를 넣는다.

- 문구 "첫 데이터베이스를 연결해 보세요"와 지원 DB 칩을 보여 준다.
- "연결할 때 필요한 정보" 목록을 둔다.
- 버튼은 "시작하기", "SQLite 파일 열기", "연결 가져오기…"(파일에서)다. 새 컴퓨터에서 내보낸 파일로 옮겨 오는 경우가 바로 이 화면이기 때문이다.
- 저장 위치·키체인 안내와 `make run DEMO=1` 안내를 함께 둔다.

## 그룹

- **그룹 데이터**는 localStorage에 `{ id, name, color, collapsed }` 목록으로 저장한다.
- **소속**은 연결의 메타(`group`)에 그룹 **id**로 저장한다. 기존 데이터는 그룹 **이름** 문자열이므로, 처음 읽을 때 같은 이름의 그룹을 만들고 id로 바꾼다.
- **만들기**: 오른쪽 클릭 → 새로 만들기 → 그룹…, 또는 + 메뉴 → 새 그룹…. 이름을 묻는 작은 창이 뜨고, 색은 고를 수 있다(기본은 순서대로 돌아가는 팔레트). 빈 그룹도 남는다.
- **넣기·빼기**: 연결 줄을 그룹 머리줄이나 그룹 안의 줄 위로 끌어다 놓으면 그 그룹에 들어간다. "그룹 없음" 영역으로 끌어다 놓으면 그룹에서 빠진다. 끄는 동안 놓일 곳을 표시한다.
- **그룹 메뉴**(오른쪽 클릭): 이름 바꾸기…, 색 바꾸기, 그룹 삭제. 그룹을 지우면 안의 연결은 그룹 없음으로 옮겨지고, 프로필은 남는다.
- **연결 편집 창**: "그룹" 칸을 없앤다. 그룹은 홈에서만 다룬다.

## 오른쪽 클릭 메뉴

`ContextMenu`에 하위 메뉴(›)를 더한다. 마우스와 키보드(→ 열기, ← 닫기) 모두 지원한다.

| 어디서 | 항목 |
|---|---|
| 연결 줄 | 열기 · 새 창에서 열기(열려 있을 때) · 편집… · 복제 · 그룹으로 이동 › · ── · 새로 만들기 › · 내보내기 › · ── · 삭제 |
| 그룹 머리줄 | 이름 바꾸기… · 색 바꾸기 › · 그룹 삭제 · ── · 새로 만들기 › · 내보내기 › |
| 빈 곳 | 새로 만들기 › · 내보내기 › |

하위 메뉴:

- **새로 만들기 ›**: 그룹… · 연결… · 연결 가져오기 › (URL에서… · 파일에서…)
  - 그룹 안에서 "연결…"을 고르면, 저장할 때 그 그룹에 넣는다.
- **내보내기 ›**: 전체 내보내기… · 이 그룹 내보내기…(그룹 위·그룹 안에서만) · 이 연결 내보내기…(연결 위에서만)
- **그룹으로 이동 ›**: 그룹 목록(지금 그룹은 체크 표시) · ── · 그룹 없음. 끌어 놓기를 못 쓰는 키보드 사용자나, 가져온 연결을 여러 개 옮길 때를 위한 길이다. 끌어 놓기가 주된 방법이라는 점은 그대로다.

**복제**는 같은 설정으로 "<이름> 복사본"을 새로 저장한다. 메타(색·태그·그룹)도 복사한다. 저장된 비밀번호는 복사하지 않으므로, 처음 연결할 때 비밀번호를 묻는다.

## 가져오기·내보내기

**내보내기**

- 브라우저 다운로드로 JSON 파일(`tablepeek-connections.json`)을 받는다.
- 내용: 형식 버전, 그룹 목록, 연결 목록(서버 프로필의 연결 설정, 이름, 색·태그·그룹).
- 비밀번호, SSH 비밀번호, 프록시 비밀번호는 절대 넣지 않는다. 키 파일 경로는 넣는다.

**가져오기 › 파일에서**

- 브라우저 파일 선택(`<input type=file>`)으로 JSON을 읽는다.
- 그룹은 이름이 같으면 합치고, 없으면 만든다. 연결은 새로 저장한다. 이름이 겹치면 " (가져옴)"을 붙인다.
- 형식이 틀리면 설명이 붙은 오류를 보여 준다(`ErrorNotice`).
- 끝나면 몇 개를 가져왔는지 알려 준다.

**가져오기 › URL에서**

- `postgres://…`, `mysql://…` 같은 연결 URL을 받는 작은 입력 창을 띄운다.
- 확인을 누르면 새 연결 창이 그 URL로 채워진 상태로 열린다. 연결 창에 이미 있는 URL 해석 기능을 쓴다.

## 백업·복원 흐름

1. 왼쪽 칸의 "데이터베이스 백업…" 또는 "데이터베이스 복원…"을 누른다.
2. 연결을 고르는 작은 창이 뜬다. 목록과 검색은 홈과 같은 줄 모양을 쓴다.
3. 고른 연결이 열려 있지 않으면 연결한다. 비밀번호가 필요하면 지금처럼 연결 창이 물어본다.
4. 그 연결의 작업 화면으로 들어가면서 기존 백업·복원 창(`DumpModal`)을 연다. 백업이면 백업 탭, 복원이면 복원 탭이다.

## environment 제거

- 연결 편집 창의 환경 선택칸, 헤더 연결 탭의 환경 배지(DEV/PROD), 홈의 환경 알약, 스키마 사이드바의 `data-environment` 표시와 관련 CSS를 없앤다.
- `connMeta`를 처음 읽을 때 environment 값이 있으면, 같은 이름의 태그(`local`/`development`/`staging`/`production`)를 추가하고 environment를 지운다. 그룹 이름으로 environment를 추측하던 코드도 지운다.

## 아이콘 크기

- 앱 전체 아이콘을 키운다. 지금 `icons.tsx`의 `ICON_SCALE`은 1.3이고, 약 1.5로 올리는 것을 기준으로 한다.
- 올린 뒤 툴바, 사이드바, 탭, 그리드 헤더, 모달 버튼에서 아이콘이 버튼 밖으로 넘치거나 줄 높이가 깨지지 않는지 화면으로 확인하고, 필요한 곳의 버튼 크기를 맞춘다.
- DB 로고 배지(`DriverIcon`)는 크기 체계가 따로이므로 이 배율의 영향을 받지 않는다. 시작 창 목록에서는 지금 홈 카드(34px)와 비슷한 크기를 쓴다.

## 만드는 사람이 정할 것

- 정확한 간격, 색 팔레트 값, 애니메이션.
- 좁은 화면에서 창이 꽉 차는 기준.
- 끌어 놓기의 세부 표시(놓을 곳 강조 모양).
- 그룹 색 팔레트 구성.
- 내보내기 JSON 필드 이름. 형식 버전은 넣는다.
- 지금 `HomeScreen.tsx`·`styles.css`의 홈 코드는 새 구조로 바꾸면서 쓰이지 않게 되는 부분을 지운다.
